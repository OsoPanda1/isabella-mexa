## 🏛️ 1. ¿Qué es Isabella Villaseñor AI?

**Isabella Villaseñor AI** no es un chatbot convencional, ni un simple *wrapper* de modelos de lenguaje (LLMs), ni pretende presentarse como una AGI consciente insustentable.

Técnicamente, Isabella es una **Infraestructura Cognitiva Territorial (Territorial Cognitive Infrastructure - TCI)** híbrida, contextualizada y gobernada, concebida en Real del Monte, Hidalgo. Constituye la capa cognitiva e interfaz humana de **Nodo Cero** y **RDM Digital**.

### Principio de Soberanía e Independencia de Modelos
En la arquitectura de Isabella, **los modelos generativos son capacidades subordinadas e intercambiables**. Isabella no se define por el modelo de IA subyacente que genera los tokens (ej. Gemini 3.7, GPT, Claude o Llama), sino por el sistema superior de **gobernanza C.R.O.W.N.**, la memoria contextual jerárquica, las políticas de seguridad **ARGUS Sentinel** y el arraigo en el territorio.

## 🎯 2. Problema Identificado y Propuesta de Solución

### El Problema de la IA Convencional
1. **Extractivismo Cognitivo y Monopolio Tecnológico**: Los sistemas tradicionales centralizados en el Norte Global imponen un sesgo epistémico anglosajón, tratan los datos locales como insumos pasivos y carecen de anclaje territorial.
2. **Ausencia de Gobernanza Computacional**: Los chatbots convencionales operan bajo el paradigma inseguro *"el modelo genera y la interfaz muestra"*, sin filtros éticos deterministas pre- y post-inferencia.
3. **Vulnerabilidad a Alucinaciones sin Auditoría**: Falta de registros inmutables sobre el porqué una IA toma una decisión o ejecuta una herramienta.

### La Solución Isabella Villaseñor AI
1. **Soberanía Tecnológica desde América Latina**: Contexto, memoria y gobernanza pertenecen a la comunidad de Real del Monte y al Sur Global.
2. **Gobernanza C.R.O.W.N. en 5 Pilares**: Un pipeline riguroso: *Ingestión → Interpretación → Evaluación de Riesgo (ARGUS) → Política → Inferencia/Herramientas → Verificación → Auditoría Inmutable*.
3. **Dualidad Inferencia Soberana**: Capacidad de alternar en caliente entre **Inferencia Cloud Federada** (para máxima potencia analítica) y **Motor Soberano Local** (*Air-Gapped / On-Premise*).
4. **Trazabilidad Criptográfica Inmutable**: Libro diario digital **BookPI** que firma cada transacción mediante perfiles poscuánticos `CRYSTALS-LATAMV` y validación `LITLE-32 Gates`.

## 🛠️ 7. Instalación y Ejecución Local

### Requisitos Previos
- **Node.js**: v18.0.0 o superior (Probado en Node.js v24.18.0).
- **npm** o **bun**.

### Pasos de Instalación

1. **Clonar el repositorio**:
   ```bash
   git clone https://github.com/OsoPanda1/isabella-mexa.git
   cd isabella-mexa
   ```

2. **Instalar dependencias**:
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Configurar variables de entorno** (opcional para inferencia Gemini Cloud):
   ```bash
   cp .env.example .env
   ```
   *Edita `.env` e ingresa tu `GEMINI_API_KEY` (si no se proporciona, el sistema conmuta automáticamente al Motor Soberano Local).*

4. **Ejecutar en Modo Desarrollo (HMR)**:
   ```bash
   npm run dev
   ```
   *Abre tu navegador en:* `http://localhost:3000`

5. **Compilar para Producción**:
   ```bash
   npm run build
   ```
   *Los artefactos se generarán en `dist/index.html` y `dist/server.cjs`.*

6. **Iniciar Servidor de Producción**:
   ```bash
   npm start
   ```
